# 宿主与能力边界

核对日期：2026-09-12。官方来源：https://learn.chatgpt.com/docs/build-skills 。

| 宿主 | 使用方式 | 验证范围 |
|---|---|---|
| Codex 本地 | 将完整技能放入 ~/.agents/skills 或项目 .agents/skills；$portrait-forge | 本次验证了复制安装及安装目录脚本执行，未改当前用户全局目录、未执行新会话选择器测试 |
| ChatGPT Work | 已安装可用技能可通过 @ 选择；安装入口按账户实际能力 | 本次未在线导入或激活，不承诺统一 ZIP 上传入口 |
| 可读附件的会话 | export_work 输出的合并资料 + 开场指令 | 已验证导出覆盖规则，属于会话资料而非持久安装 |
| 通用 Agent Skills 宿主 | 使用 SKILL.md 及相对路径资源，忽略不支持的 agents/openai.yaml 元数据 | 需在目标宿主完成行为评估 |
| 无代码执行 | 读规则、人工核对、输出 Prompt | 不报告自动程序 PASS |

没有图像工具不会阻止文字设计；有工具也不自动生成图片。用户明确要求生成时按宿主流程处理；布尔字段只记录意图。无图像读取能力时不能声称已分析参考图或验证结果。

资料包包含全部规则与字段目录，不包含运行时 Python；需要自动校验时同时提供完整 Skill 并确认宿主可执行文件。本项目没有调用在线 API、不要求登录、不保存密钥。

不要将项目 manifest.json 当作插件标准文件。它只记录本工程发布内容。若以后要分发插件，应另按对应宿主的插件规范包装与验收。
