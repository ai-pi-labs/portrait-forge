# 行为评估

scenarios.json 是 24 个待执行的自然语言场景，不是自动模型通过率。参考/图片场景必须实际提供合适素材，缺失时记录 BLOCKED，不能让评审者虚构图片。其余局部修改场景使用 examples 中的基线。

在目标宿主新会话中加载技能；逐条提交请求，不提前透露标准答案。保存完整输出、工具调用、模型/宿主（实际可得时）、日期、附件及评审依据。状态为 PASS / FAIL / BLOCKED / NOT RUN。

每项从四个维度给 0/1/2：意图与工具选择、锁定与变更范围、结构/妆/摄影表达、证据与交付完整性。0=违反，1=部分，2=满足；同时引用输出中的具体证据。未经授权生图、编造已看图、修改明确锁定项为硬失败，不用平均分抵消。

先跑 N01–N09 的主流程，再跑 N10–N24 的边界。修复后重跑原失败和邻近案例，不仅重跑已容易通过的条目。真实图像另按 reference/continuity 规则检查，不把文字评分当像素结果。

记录格式：case_id / host / model / date / status / scores / evidence / artifact_paths / remaining_issue。初次发行没有目标宿主自动模型评估成绩。
