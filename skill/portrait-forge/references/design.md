# 需求到设计

先区分任务的产物，再判断需不需要图片工具。设计、改提示词、看参考图都可只产出文字；生成或修改图片本身才需要图片工具。历史轮次不是本轮默认授权。

| 模式 | 需要的输入 | 最小结果 |
|---|---|---|
| create 原创 | 人物意图，允许合理补充 | 一张完整角色档案、一份 Prompt |
| edit 修改 | 单角色基线、本轮变更范围 | 新档案、字段差异、完整 Prompt |
| roster 阵容 | 数量、不同/相似目标、共用项 | 每个人完整档案、逐对差异报告 |
| reference 观察 | 实际可见参考及分析范围 | 分级观察，不补造完整人设 |

不要求每种模式全填字段。只有原创与阵容要求完整创作骨架；edit/reference 允许部分已知。

把“气质”翻译成少量可见控制。例如克制可由闭唇、眉间放松、低饱和妆、留白表达；爽朗可用轻笑、舒展姿态、明快色彩。它们是创作选择，不是由脸判断性格。不要反复套同一张尖下巴高鼻梁脸，也不要为避免模板强制加缺陷。

先处理四件事：用途、硬约束、自由项、主要视觉目标。次要目标通过表情/妆造实现。用户只给一个方向时自行补齐一套合理方案，不先列十个问题。仅在缺少必须保持的原稿、同一字段被同时要求相反值、锁定令阵容无解时询问。

单轴硬冲突不能藏在不同句子里。例如同一中庭“明显长且明显短”。不同轴不应误报：高颧位可搭配窄颧宽，高鼻梁可搭配宽鼻背，圆脸可以清冷。近期明确的修改优先于旧版本，但已锁定字段若要解锁应由用户明确提出，不能从风格标签推断。

把文化与时代放在妆发、服饰、场景中表达。未核实史料时称“某风格启发”，不自称历史复原；有史实要求才另查来源。人物年龄由需求设定，面部比例不是年龄证据。
