# 妆容与摄影的控制范围

每一处妆描述包含需要控制的颜色、相对位置、边缘、方向、覆盖强度与材质。一个字段可用简短完整句，不只写“高级妆”。唇色、唇质地、唇缘分为三个字段，让单项修改可检查。

| 需求 | 可以选择 | 应保留 |
|---|---|---|
| 圆脸保留饱满 | 双颊中央柔边、横向铺色 | 原有脸宽与下巴 |
| 在圆脸上增加上提妆效 | 外颧轻斜延、缩短眼线 | 不把骨骼削窄 |
| 单眼皮轻妆 | 按睁眼可见区域薄铺，贴根线 | 原生眼睑 |
| 天然下垂眼尾配上挑线 | 分写眼尾与画出的线 | 自然眼角方向 |
| 深肤色桃粉妆 | 调整覆盖与色彩可见性 | 基础肤色，不以提白解决 |
| 只换唇色 | 修改 makeup.lip_color | 光泽、边缘、自然唇厚不动 |
| 无妆 | 各妆字段明确“无附加…” | 不用缺字段表示无妆 |

同妆在本版本中定义为全部 makeup 字段值完全相同，描述采用相对位置，脸不同自然对应不同实际面积。若要改变上色逻辑或强度，成为新妆容版本，不再称严格同妆。自由文本语义相同但文字不同仍会报差异，先统一用词，不绕过校验。

摄影必须选定媒介、景别与边界、视角、光线、背景。需要完整发髻/手臂时在 framing 写出并为其留白；避免胸像却要求展示膝部。柔光用光源大小、方向与补光表达；水光唇和柔雾皮肤可共存，全脸高光与哑光要求要分区。肤色不靠过曝实现。

角色对照图建议先固定正面或轻侧角、柔和均匀光和相近景别，再评估脸。艺术性强侧光可用于成片，但不宜作为唯一身份比较证据。焦距等数字仅为描述性意图；不声称工具实际使用了相机参数。

编译后检查头发遮眼、帽沿遮颧、逆光、强表情是否使要求的特征不可见。用户锁定这些摄影条件时保留并说明可验证范围，不偷偷换构图。
